# PlantProcess IQ Frontend `.implementation` Wrapper Pattern

Generated by Pack B-4A.

## Purpose

Some frontend public files are intentionally kept as tiny compatibility wrappers so existing imports remain stable while larger implementations are decomposed or migrated behind them.

## Current rule

- `*.implementation.ts(x)` files should stay thin where possible.
- Public wrappers may re-export from a sibling runtime or split module.
- Long runtime files are temporary compatibility anchors and must be treated as future semantic split targets, not as a new preferred style.
