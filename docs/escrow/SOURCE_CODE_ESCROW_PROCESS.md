# PlantProcess IQ Source-Code Escrow Process

## Escrow content

- Source code snapshot
- Build instructions
- Database scripts
- Open-format export schema
- Deployment runbooks
- License verification documentation
- Third-party dependency list

## Release conditions

Source release is controlled by signed commercial contract conditions, such as:

- Vendor insolvency
- Contract-defined continuity trigger
- Verified failure to support licensed on-prem instance
- Court/escrow-agent approved release condition

## Customer portability

Customers can receive open-format exports independently of source escrow.
