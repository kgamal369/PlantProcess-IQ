# T-177 verification instruments

Three scripts that produced the evidence in `T-177_Parity_Matrix.md` and
`T-177_Closure_Evidence.md`. They are committed so the evidence is reproducible.

**They do not touch the repository.** They read nothing from it and write nothing to it.

| Script | Proves | Needs |
|---|---|---|
| `verify_fixtures.py` | Every expected value in the fixture pack re-derived from first principles | Python 3 only |
| `algo_proof.py` | The exact special-function algorithms in `SpecialFunctions.cs`, ported line for line, reach the fixture p-values to about 1e-12 relative | Python 3, scipy |
| `kernel_sim.py` | Every fixture routes to the branch its expectation demands, both falsification cases included | Python 3, scipy |

```
python verify_fixtures.py
python algo_proof.py
python kernel_sim.py
```

## Why a second source exists at all

The fixture pack was generated by scipy and then recomputed independently without it.
The two disagreed on the Kruskal-Wallis statistic by 0.0334, because the first hand
calculation omitted the tie correction. The reference was right. Without the second
source, a tie-blind expectation would have been written into the contract and every
later implementation would have inherited it.

Industrial data is heavily tied. Sensors quantise, setpoints repeat, categories are
coarse. A tie-blind Kruskal-Wallis is systematically wrong on exactly the data this
product exists to analyse, and wrong in the direction of understating the statistic.
