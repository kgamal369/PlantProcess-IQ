PlantProcess IQ is licensed by edition. Feature availability is governed by a signed entitlement resolved by a single backend authority that both the interface and the API consult, so a capability that an edition does not include is shown disabled and cannot be reached by calling the API directly.

## Editions

| Edition | Intended for | Included capability |
|---|---|---|
| Light | A first connected plant and core investigation | Source integration, staging, canonical mapping and genealogy, dashboards and KPIs, on-demand correlation analysis |
| Pro | A plant operating the product daily | Everything in Light, plus scheduled learning jobs, the value engine, widget customization with the script layer, and the jobs monitor |
| ProPlus | An advanced plant team | Everything in Pro, plus advanced widget authoring, expanded analytical methods, and extended role scoping |
| Enterprise | A multi-plant or fleet operator | Everything in ProPlus, plus multi-plant scope, dedicated or on-premise deployment options, and enterprise administration |

The capability split above is indicative. The precise feature matrix per edition is confirmed in a proposal.

## What is included

A subscription includes the platform, product updates within the licensed edition, and standard support. Onboarding assistance, historical backfill support, and any dedicated or on-premise deployment are scoped per agreement. Support terms and data-handling commitments are provided as part of a proposal.
